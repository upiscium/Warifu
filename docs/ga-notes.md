# v0.3.1 GAノート

未署名の手動配布アーカイブです。アーカイブと独立に入手したチェックサムを照合してください。チェックサムは未署名配布物の真正性を保証しません。

## 変更点

- v0.3.0 から、アプリ既定の1ファイル上限は50 GiBから10 GiBに、要求単位の累積ハッシュ予算は1 GiBから50 GiBに変わります。SHA-256 ETag計算はファイル全体を読むため、部分読込でも予算を消費し得ます。
- 管理者設定で各値を独立に1〜4294967295 GiBの整数に設定できます。既存のv0.3.1-rc.1で保存済みの予算設定は更新後も維持されます。
- PHPは64-bitが必要です。

このリリースの製品PHPコードは公開済みRC1と同一で、アプリ版情報のみが異なります。設定値は `config.php` のファイル上限やユーザーごとのバイト上限を引き上げません。設定値とそれらの上限が競合する場合は、より低い上限が適用されます。既存環境で明示されたファイル上限が10 GiBより大きい場合、新しいアプリ既定値により実効上限が小さくなることがあります。

## 対象と注意

対象は Nextcloud 35.0.3、64-bit PHP 8.5.12、通常の非暗号化ローカルホームです。外部ストレージ、暗号化、サブマウントは対象外です。新規導入のscope既定値は全ユーザー対象、更新時は既存動作を維持します。

配布アーカイブは `nextcloud_gateway-0.3.1.tar.gz`（43103 bytes）、SHA-256は `52dfa3713c45169018eea397fd5e272de0e0402c930560e88e542280bffaf9af` です。

Redisロックによる同じパスへの同時作成では、両要求に `423 Locked` が返る場合があります。競合時の注意とこのアーカイブの確認範囲は[検証記録](qualification.md)を参照してください。
