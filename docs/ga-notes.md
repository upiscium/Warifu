# Warifu v0.2.0 — GAノート

## リリース情報

- バージョン：`0.2.0`
- アプリID：`nextcloud_gateway`
- 配布方式：未署名アーカイブの手動導入
- 自動更新：この手順では提供・保証しません

製品ファイルのRC1からの差分は `appinfo/info.xml` の版番号のみです。[RCの変更点と検証範囲](rc-notes.md)を引き継ぎます。0.1.0からは1ファイル50 GiB、一覧2048項目（自身込み）、累積ハッシュ1024 MiB/要求、協調的期限300秒に変わります。全体をハッシュする操作は、サイズ上限より先にハッシュ予算に達することがあります。既定の期限を使う場合 `filelocking.ttl` は最低1200秒必要です。

## 配布アーカイブ

照合する対象はGitHubの自動生成ソースではなく次のインストール用アーカイブです。

- ファイル名：`nextcloud_gateway-0.2.0.tar.gz`
- SHA-256：`a48403b7dcb67947f57be734e4462c53ac9a175045b95aa14a753a6313f92766`
- バイト数：`39139`

導入前に、配布元が別途提供するチェックサム情報との一致を確認してください。値が未置換、チェックサムが入手不能、または不一致の場合は導入・更新を中止してください。未署名であるため、このチェックサム照合だけで配布元の真正性が保証されるわけではありません。

## 更新経路

手動更新手順はRC1（`0.2.0-rc.1`）および正式版`0.1.0`からの更新を扱います。対象外の版からはこの手順を流用せず、バックアップを確保して管理者の移行計画に従ってください。更新前に必ず[更新・ロールバック手順](upgrade.md)を確認してください。
