# Warifu v0.3.0 — GAノート

## リリース情報

- バージョン：`0.3.0`、アプリID：`nextcloud_gateway`
- 未署名の手動導入用アーカイブ。自動更新は提供しません。
- 対象として限定する環境：Nextcloud 35.0.3、PHP 8.5.12、通常の非暗号化ローカルホーム。

新規インストールでは全モードが既定です。既存インストールのアップグレードでは全体へ拡張しません。旧 `experimental_enabled=yes` は選択登録相当、それ以外（未設定を含む）は停止状態へ移行します。管理者が設定画面で明示的に適用範囲を選んでください。

## 配布アーカイブ

インストール用アーカイブを、配布元が別途提供するチェックサム情報と照合します。GitHubの自動生成ソースアーカイブとは別物です。

- ファイル名：`nextcloud_gateway-0.3.0.tar.gz`
- SHA-256：`09b93665a07bf2ac0e0f5a539a1007a2a6aa9d989e2418b151d0f50dca296fe5`
- バイト数：`41647`

値が未置換、独立した照合値が入手できない、または不一致なら導入を中止してください。未署名のため、チェックサム照合のみで配布元の真正性は保証されません。

## 範囲と注意

外部ストレージ、暗号化、サブマウント構成は対象外です。サイズ上限と累積ハッシュ予算は別の制約です。SHA ETag計算ではファイル全体を読むため、ファイルがサイズ上限未満でも要求単位のハッシュ予算超過となる場合があります。

更新元の仕様は [v0.2.0 の文書](https://github.com/upiscium/Warifu/tree/v0.2.0/docs) を参照してください。
