# Warifu 0.1.0 リリースノート

## 配布形態

0.1.0 は未署名の手動導入版です。署名済みApp Store配布や自動更新は対象外です。[新規インストール](install-nextcloud.md)または[rc.3からの更新](upgrade.md)を参照してください。

## 機能と変更

機能コードは `0.1.0-rc.3` と同一です。このリリースでコード変更、機能追加、互換性拡張を行ったものではありません。GA という版名だけを根拠に新しい試験実績や本番保証を解釈しないでください。

アプリは Nextcloud 標準 Files WebDAV で内容 SHA-256 ETag、条件付き更新、制限された単一ファイル操作、および標準アップロード経路のガードを提供します。標準 DAV 全機能の代替・完全互換を保証しません。条件付きコレクション操作、対象外名前空間、対応外ロック／ストレージなどの制限があります。

## 固定ランタイムと適用範囲

- Nextcloud **35.0.3**
- 固定した公式 Apache イメージ、PHP **8.5.12**
- 暗号化なしのローカルユーザーホーム、明示登録したユーザー／サブディレクトリ

異なる Nextcloud 版、外部ストレージ、暗号化、すべてのクライアント構成、任意環境での本番利用は保証対象外です。`allowed_roots` は認可境界ではなく、App Password のアクセス権も制限しません。

## 試験状況

SHA-256 `60710d7b1f5ca0eeeccc83814cc9ad0c0edc644461ea452af599e35a4c17ad3f` のGAアーカイブを使用し、隔離したNextcloud 35.0.3／SQLiteで次を確認しました。

| 操作 | 実測 |
| --- | --- |
| GA新規導入 | `installed_version=0.1.0`。匿名401、認証207、条件付き作成201、古いETagで412、再取得200 |
| rc.3→GA | 標準 `occ upgrade` で更新。既存ノート・App Password・登録範囲を維持し、更新204／競合拒否412 |
| 通常DAVへ復帰 | feature flagを無効化し、全Webワーカー入替後にGET 200、本文不変・ネイティブETag・Gatewayヘッダーなし |
| rc.3復元 | 更新前の設定・データ・SQLite DB・コードを同一時点へ復元。元のApp Passwordで旧本文を取得し、条件付き更新に成功 |

設定無効化直後にワーカーを入れ替えず判定した初回試験では、通常DAVへの復帰を確認できませんでした。即時反映を前提にせず[更新・切戻し手順](upgrade.md)に従ってください。MariaDB／Redis回帰と実NASの3クライアント往復は[RCの実績](rc-notes.md)で、GAの実NAS再試験ではありません。固定Coreの通常pushには既知の不適合があります。
