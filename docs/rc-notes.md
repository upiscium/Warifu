# Warifu 0.1.0-rc.3 — プレリリース候補

標準WebDAVの登録フォルダで、内容SHA-256の強いETagと条件付きファイル更新を利用できます。新しいクライアントAPI、認証プロキシ、Nextcloudコアの変更は不要です。

**手動インストール用（未署名）**: `nextcloud_gateway-0.1.0-rc.3.tar.gz`（38,897 bytes）

```text
fc109382044df1cf1d3be733a53730ef707ec691777c482318dbd3578bb689a0  nextcloud_gateway-0.1.0-rc.3.tar.gz
```

新規導入は [管理者向け手順](install-nextcloud.md) を参照してください。既存の開発版 `0.1.0` からのダウングレードには使わないでください。アーカイブ名・アプリIDは検証済みのものを維持しています。

### 確認したこと

- PHP単体試験670 assertions。サーバー回帰はSQLite構成162件、Redis構成164件、MariaDB構成162件。MariaDBの容量境界試験9件。
- 実NASの専用Vaultで、匿名DAVは401、App Password認証は207。条件付き作成201、正しいETagでの更新204、古いETagでの更新拒否412を確認しました。
- 合成ノート1件について、Automationによる作成、デスクトップObsidianと派生Coreによる編集、Nextcloud Filesでの置換を行い、最終の再取得内容が一致しました。WebUI試験は初回の画面移動で停止し、同じ編集済みノートから継続して成功しました。

### 適用範囲

- Nextcloud 35.0.3の固定ランタイム、通常の非暗号化ローカルホーム、検証済みのDB／Redisロック構成に限ります。登録はインスタンス全体、内容ETagの対象は登録フォルダです。ディレクトリ自体のETagはネイティブのままです。
- 1ファイル64 MiB、1一覧512 entries（自身を含む）、要求あたりのハッシュ256 MiB、協調的時間制限30秒です。無条件書込み、任意のコレクション操作、外部ストレージ・共有リンクまで同じ競合保護を提供するものではありません。
- 未修正の固定ObsidianCore-Syncではgzip履歴応答の長さ検査で通常pushに失敗しています。成功した派生クライアントはこの配布物に含みません。モバイルや長期の自動同期、RCからGAへのアップグレードは未認定です。
