# v0.3.1-rc.1 RCノート

これは未署名のリリース候補です。運用環境への適合性を管理者が確認してから使用してください。アーカイブと独立に入手したチェックサムを照合してください。チェックサムは未署名配布物の真正性を保証しません。

## 変更点

- アプリ既定の1ファイル上限を50 GiBから10 GiBへ変更。
- 要求単位の累積ハッシュ予算を1 GiBから50 GiBへ変更。SHA-256 ETag計算はファイル全体を読むため、部分読込でも予算を消費し得ます。
- 管理者設定で各値を独立に1〜4294967295 GiBの整数に設定可能。
- PHPは64-bitが必要。

これらのアプリ設定は `config.php` のファイル上限もユーザーごとのバイト上限も引き上げません。既存環境で明示されたファイル上限が新しい既定値10 GiBより大きい場合、新しい既定値により実効上限が小さくなることがあります。実際の上限は各層の制約に従います。

## 対象と注意

対象は Nextcloud 35.0.3、64-bit PHP 8.5.12、通常の非暗号化ローカルホームです。外部ストレージ、暗号化、サブマウントは対象外です。scopeの動作はv0.3.0から継承します。新規導入の既定は全ユーザー対象、更新時は既存動作を維持します。

Redisロックで同じパスに同時作成すると、両方に `423 Locked` が返る場合があります。[このRCアーカイブの検証結果と、競合時の再試行方法](qualification.md)を参照してください。
